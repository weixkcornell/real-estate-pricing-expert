# 空间计量与机器学习估值 · Checklist

用法：建模前逐项打勾。

## 空间诊断
- [ ] Moran's I / LISA 已完成
- [ ] 空间权重矩阵定义合理（距离 / 邻接 / 可达性）
- [ ] 已区分空间依赖 vs 空间异质，并选对模型族
- [ ] 地理编码质量已校验（地址错标排查）

## 模型选择
- [ ] 全局 OLS 系数恒定假设已被检验（不允许未检验直接全局建模）
- [ ] GWR/MGWR 已处理多重共线性与带宽选择
- [ ] ML 模型已做偏差-方差权衡与去偏
- [ ] 极端值已单独处理
- [ ] 小样本市场已改用带预测区间的空间统计模型

## 可解释与不确定性
- [ ] ML 已配 SHAP/特征归因
- [ ] 输出预测区间，不只给点估计
- [ ] 交叉验证 + 时间外样本测试完成

## 输出
- [ ] 方法适配理由 + 限制已说明
- [ ] 所有数字有来源 + 口径 + 截至期
- [ ] 无未填占位符、无编造数字
