# 成本法与假设开发法（剩余法）

## 0. 为什么必须补这个 Skill

`data-contracts/capability-contract.csv` 的 `rep.land.parcel.read` 契约里明确写着"用于**成本法**与供给分析"，但包内**没有成本法 Skill** —— 契约承诺了包内不存在的能力（评审 P1-1/P1-3，契约空头）。本 Skill 消除这个空头。

---

## 1. 两种方法的分工（**不可混用**）

| | 成本法 | 假设开发法（剩余法） |
|---|---|---|
| **回答什么** | 重新建一个要花多少 | 这块地值多少 |
| **适用** | 市场交易稀疏（新建区、特殊用途物业、工业厂房）、保险与税务、重置价值评估 | **土地估值与在建工程**（首选方法） |
| **不适用** | **住宅正常交易估值** —— 中国住宅价格含大量区位与制度租值，成本与价格无稳定关系 | 已建成物业的市场价值评估 |
| **在本包中的地位** | 交易法估值的**下限校验**，不作主结论 | 土地/在建工程**首选** |

## 2. 成本法

### 2.1 基本式（积算式）

```
价值 = 土地取得成本 + 建筑物重置成本 + 管理费用 + 销售费用
      + 投资利息 + 销售税费 + 开发利润 + 土地取得税费
```

或**重置成本法**：

```
价值 = 土地重置成本 + 建筑物重置成本 × 成新率
```

### 2.2 关键参数与陷阱

| 项 | 要点 | 陷阱 |
|---|---|---|
| 土地取得成本 | 出让金（起始价/成交价）+ 相关税费 | **不得用评估地价反推后再算房价**（循环） |
| 建筑物重置成本 | 建安工程费 + 前期费 + 基础设施 + 公共配套 | **必须按建成年份分档** —— 同结构类型下 2000 年代与 2020 年代的交付标准差异巨大 |
| 开发利润 | 按**社会平均利润率**或行业惯例 | **不得用项目实际利润率**（那是项目业绩，不是市场成本） |
| 投资利息 | 土地按全额、建造按**均匀投入**分段计息 | 计算基数含土地与开发成本，**不含利润与税费** |
| 建筑物折旧 | 物理 + 功能 + 经济三项 | 年限法过于粗糙；**经济折旧须独立判断**（区位衰落、需求转移） |

### 2.3 折旧的两种方法

| 方法 | 公式 | 何时用 |
|---|---|---|
| **年限法** | 成新率 = 剩余年限 / 总使用年限 | 常规标的快速估算；**不能反映功能与经济折旧** |
| **观察法** | 成新率 = 1 − 物理折旧 − 功能折旧 − 经济折旧 | 重要标的；**须与年限法交叉验证** |

> ⚠️ 年限法的一个典型错误：一栋 30 年房龄的房子，若仅因年限给出 40% 成新率，可能严重低估其实际价值（核心区老房可能因学区或地段几乎没有经济折旧）。

## 3. 假设开发法（剩余法）

### 3.1 基本式与**解析解**

```
土地价值 V = [ V_dev·(1 − t_sale) − C·(1 + b + p) ] / (1 + a + p + t_land)
```

其中：
- `V_dev` 开发完成后房地产价值（用比较法或收益法求得——**不可用成本法，否则循环**）
- `C` 后续开发成本（建安 + 前期 + 基础设施 + 公共配套），按可售面积比例调整
- `p` 开发利润率，**基数为 (V + C)**
- `t_sale` 销售税费率，`t_land` 土地取得税费率
- `a = (1+i)^n − 1` 土地全额计息因子；`b = (1+i)^(n/2) − 1` 建造成本均匀投入计息因子

### 3.2 最易出错处：**利润基数的代数循环**

静态法中若利润以"土地价值 + 开发成本"为基数，而土地价值正是待求量：

```
V = V_dev − C − p·(V + C) − …        ← V 出现在等式两边
```

**必须解方程，不能迭代估计**。迭代会收敛到错的解或发散。`cost_residual.py` 用解析解，并内置验算（各项合计应精确等于 `V_dev`）。

**利润基数的两种口径**（须择一并在报告中说明）：
1. 以 **(土地价值 + 开发成本)** 为基数 —— 本包默认
2. 以 **开发完成后价值** 为基数 —— 结果显著不同，数值通常更低

两种口径混用是常见错误。

### 3.3 出让条件必须建模
配建（保障房、幼儿园）、自持年限、限价、限售都会实质改变剩余价值：

```
可售面积比例 = (总建筑面积 − 配建面积 − 自持面积) / 总建筑面积
```

不建模会**系统性高估地价**。`cost_residual.py` 的 `--saleable-ratio` 即为此参数。

## 4. 土地增值税（超率累进）

不可用简单比例税费率替代。按增值率（增值额 / 扣除项目金额）分档累进，含速算扣除系数。

> ⚠️ 本包 `lvt_ultra_progressive()` 内置的分档比例与速算扣除系数为**结构示意**。中国土地增值税规定经过多次调整，**引用前必须复核当期税法原文**，并在报告中标注依据文件与生效日期。

## 5. 必须输出的内容

1. **公式与参数表**：列出每个参数的取值与依据（不是只给终值）
2. **构成表**：各项成本/费用/利息/利润分项列示
3. **验算**：假设开发法须给"各项合计 = 开发完成后价值"的闭合验算
4. **二维敏感性**：利润率 × 利息率（剩余法）；重置成本 × 成新率（成本法）
5. **口径与限制声明**：成本法的适用边界、建安单价的来源与年份、折旧方法与其局限
