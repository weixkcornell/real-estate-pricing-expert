# 成本法 / 假设开发法 作业清单（逐项打勾）

> 对应 Skill：`skills/cost-residual/SKILL.md`

---

## A. 方法选择（先决判断）

- [ ] 已确认本标的**适用方法**：
  - [ ] 市场交易稀疏 / 特殊用途 / 保险税务 / 重置价值 → **成本法**
  - [ ] 土地 / 在建工程 → **假设开发法（剩余法）**
  - [ ] 住宅正常交易估值 → **不应以成本法为主结论**（只能作下限校验）
- [ ] 已确认**未发生循环论证**：未用成本法的结果去反推土地取得成本，再用该成本算房价

## B. 成本法

- [ ] 土地取得成本的来源与口径已标注（起始价 / 成交价；须统一到**楼面地价**）
- [ ] 建筑安装工程费单价**按建成年份分档**，未全市统一一个均价
- [ ] 建安单价来源已标注（当期当地造价信息 / 造价咨询），**未使用示意值**
- [ ] 开发利润取**社会平均利润率**或行业惯例，**未使用项目实际利润率**
- [ ] 投资利息：土地按全额、建造按**均匀投入**分段计息，**基数不含利润与税费**
- [ ] 折旧方法已说明（年限法 / 观察法），且：
  - [ ] 若用年限法 → 已注明"不能反映功能与经济折旧"
  - [ ] 若为重要标的 → 已用**观察法交叉验证**
  - [ ] **经济折旧**已独立判断（未由房龄机械推导）
- [ ] 已给出**重置成本 × 成新率**的二维敏感性

## C. 假设开发法（剩余法）

- [ ] `V_dev`（开发完成后价值）由**比较法或收益法**求得，**未用成本法**（否则循环）
- [ ] 后续开发成本按**可售面积比例**调整（配建 / 自持 / 限价已建模）
- [ ] 利润基数口径已**明确择一**并说明：
  - [ ] 以 (土地价值 + 开发成本) 为基数（本包默认）
  - [ ] 以 开发完成后价值 为基数
  - [ ] **未混用两种口径**
- [ ] 用**解析解**求解，**未用迭代估计**（存在代数循环）
- [ ] 已输出**闭合验算**：各项合计 = 开发完成后价值
- [ ] 土地增值税按**超率累进**处理（未用简单比例税费率替代）
- [ ] 土地增值税分档比例与速算扣除系数**已核对当期税法原文**，并标注依据文件与生效日期
- [ ] 开发期假设已按当地**预售条件、施工许可、预售资金监管**规则设定（未套用一般工期）
- [ ] 已给出**利润率 × 利息率**的二维敏感性

## D. 输出与披露

- [ ] 已列出**完整参数表**（每个参数取值 + 依据），不是只给终值
- [ ] 已列出**构成表**（分项金额）
- [ ] 已声明成本法的**适用边界**（住宅不作主结论）
- [ ] 已声明建安单价的**来源与年份**
- [ ] 已说明折旧方法的**局限**
- [ ] 结果以**区间**给出（成本法本身单值，但参数敏感区间须给）

---

## 红线（出现任一项即判不合格）

1. 用项目实际利润率替代社会平均利润率；
2. 假设开发法的利润基数形成循环却用迭代估计；
3. 成本法结果作为住宅市场价值的**主结论**；
4. 建安单价全市统一一个均价、不分建成年份；
5. 配建 / 自持 / 限价未建模却直接给出地价结论；
6. 引用土地增值税分档比例而未核对当期税法原文。
