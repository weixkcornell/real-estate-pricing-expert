# 特征价格定价 · 建模前 Checklist

用法：建模前逐项打勾；任何一项不过，不进入估计。

## 市场与样本
- [ ] 明确城市 / 区域 / 物业类型 / 时间窗
- [ ] 已做空间自相关检验，子市场划分依据充分（非仅行政边界）
- [ ] 样本量足以支撑属性集（经验阈值：每个自变量 ≥ 10–20 观测）
- [ ] 异常值处理规则明确（分位截尾 / 稳健回归），并记录

## 属性集（四类）
- [ ] 结构属性齐全（面积、房型、楼龄、楼层、朝向、装修…）
- [ ] 区位属性齐全（就业/商圈/地铁距离、可达性）
- [ ] 邻里属性齐全（学区、物业、容积率、环境）
- [ ] 周期/制度属性齐全（交易时间虚拟变量、政策、利率）
- [ ] 缺失属性已标「待补」并说明对估值方向的影响

## 模型
- [ ] 函数形式已选定并说明理由（半对数默认）
- [ ] 多重共线性已检验（VIF），高共线变量已处理
- [ ] 异方差已处理（稳健标准误）
- [ ] 空间依赖已检验；显著则改空间模型
- [ ] 需要时已引入属性价格时变（时间×属性）

## 输出
- [ ] 给出点估计 + 区间，不做单点断言
- [ ] 输出属性贡献分解
- [ ] 稳健性检验（换形式/换属性集/分样本）已完成
- [ ] 所有数字有来源 + 口径 + 截至期
- [ ] 无未填占位符、无编造数字
