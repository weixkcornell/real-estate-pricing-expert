# 特征价格模型的价值演示（小样本实测）

> 用途：回答「为什么不能用均价定价」。本文件给出一个可复现的最小对比实验，说明特征价格模型相对朴素均价法的精度增益与可解释性增益。
>
> 数据：某小区 8 套带属性挂牌样本（公开渠道）。**n=8、3 个自变量（自由度 4），属演示性质，系数方向稳健但绝对水平不具统计显著性。**大样本上线前不得将其作为定论。

## 一、实验设计

- **朴素法（基准线）**：用样本单价均值预测每一套。这是「小区均价 × 面积」的等价形式。
- **模型法**：`ln(单价) = β₀ + β₁·面积 + β₂·南向类 + β₃·高楼层 + ε`，OLS 估计。
- **评价**：MAE（平均绝对误差）、MAPE（平均绝对百分比误差），两者在同一批样本上比较。

## 二、结果

| 方法 | MAE（元/㎡） | MAPE |
|---|---|---|
| 朴素均价法 | 3,504 | 7.06% |
| 特征价格模型 | 1,100 | 2.24% |
| **改善** | **−2,404（−68.6%）** | **−4.82 pp** |

**估计系数**

| 变量 | 系数 | 经济含义 |
|---|---|---|
| 截距 | 10.6799 | — |
| 建筑面积 | +0.00059 /㎡ | 每 +10㎡ 单价 +0.59% |
| 南向类（南北/西南/南） | +0.0657 | **+6.80%** |
| 高楼层 | +0.0880 | **+9.20%** |

## 三、结论

1. **精度**：同样的数据，只因「用了模型」，单套定价误差从 ±7% 收敛到 ±2%。
2. **可解释**：模型能回答「这套为什么便宜 20 万」——朝向贡献 6.8%、楼层贡献 9.2%，逐项归因。
3. **方向稳健、水平待扩样**：8 套中 6 套改善、2 套略差；样本量扩大后稳定性会显著提升。

## 四、使用边界

- 本演示**不得**用于替代正式 hedonic 估计。样本量达到「每个自变量 ≥ 10–20 观测」后方可定级为分析级。
- 演示暴露的本质限制：**公开挂牌数据不构成 hedonic microdata**。要跨过这道门槛，必须接入成交价微观数据。

## 五、复现要点

- 南向类定义：朝向含「南」（南北 / 西南 / 南）记为 1，其余（东 / 东西 / 东南北）记为 0。
- 因变量取对数，系数经 `exp(β)−1` 转换为百分比效应。
- 缺失属性一律标「待补」，不得插补后当实测使用。
