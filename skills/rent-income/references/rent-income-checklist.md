# 租金与收益法定价 · Checklist

用法：建模前逐项打勾。

## 租金定价
- [ ] 租金口径明确（挂牌 / 成交）并说明折算
- [ ] hedonic 租金模型属性集完整（结构 + 可达性）
- [ ] 租金指数方法已选（分层时间虚拟变量 / Box-Cox）
- [ ] 租金空间依赖/异质已处理（SAR-GWR）

## 商业地产
- [ ] NOI 计算口径已说明
- [ ] Cap Rate 按城市/物业类型分别标定（禁止跨类型套用）
- [ ] DCF 参数（折现率、租金增长、空置率、退出 cap rate）已披露
- [ ] 折现租金模型与 hedonic 结果交叉验证（如适用）

## 价格租金比 / 合理性
- [ ] 价格与租金 hedonic 使用**相同属性集**
- [ ] 用户成本法已用于基本面检验（如适用）
- [ ] 租售比的空间异质已说明

## 输出
- [ ] 租金水平/指数 + Cap Rate + 价值区间齐全
- [ ] 租金与价格背离已识别并归因
- [ ] 所有数字有来源 + 口径 + 截至期
- [ ] 无未填占位符、无编造数字
