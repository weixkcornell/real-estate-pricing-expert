# 价格指数构建 · Checklist

用法：构建前逐项打勾。

## 口径与用途
- [ ] 指数用途明确（市场监测 / 组合重估 / 抵押品定价）
- [ ] 数据口径明确（网签 / 挂牌 / 租金）并写入口径声明
- [ ] 基期与时间跨度明确

## 方法选择
- [ ] 方法族已选定并说明理由（Hedonic / Repeat-Sales / Hybrid / ML）
- [ ] 方法选择有数据条件支撑（样本量、重复成交比例）
- [ ] 若用重复销售：已披露样本覆盖率与选择偏差方向
- [ ] 若用 ML 指数：已做去偏与偏差-方差诊断（小样本警觉）

## 估计
- [ ] 重复销售已用加权最小二乘（间隔时间方差结构）
- [ ] 已处理属性价格时变（如适用）
- [ ] 已做融合或交叉验证（重复销售 + 空间 hedonic）

## 输出
- [ ] 指数序列 + 置信区间
- [ ] 方法说明可复现
- [ ] 与官方统计指数交叉验证，差异已说明
- [ ] 所有数字有来源 + 口径 + 截至期
- [ ] 无未填占位符、无编造数字
