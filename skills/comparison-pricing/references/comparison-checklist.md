# 比较法作业清单（逐项打勾）

> 对应 Skill：`skills/comparison-pricing/SKILL.md`
> 用法：动手前逐项确认；有一项不过就停，不要"先做着看"。

---

## A. 前置条件（任一不过 → 不具备比较法条件，拒绝出结论）

- [ ] **可比案例 ≥ 3 个**（1–2 个时拒绝，不得硬凑）
- [ ] 案例与估价对象**同区域、同用途、同类型**（住宅/公寓/商住不混）
- [ ] 案例成交时间距基准日 **≤ 12 个月**（市场波动期收紧至 6 个月）
- [ ] 已明确价格口径：**成交价 or 挂牌价**（挂牌价须标注并将做折算）
- [ ] 已明确标的用途与权属（商品房 / 房改房 / 共有产权 / 保障房）

## B. 案例筛选（硬性排除，不可"调整后纳入"）

- [ ] 已排除**法拍房**
- [ ] 已排除**亲属 / 关联方间转让**
- [ ] 已排除**抵债房、急售**
- [ ] 已排除**限价 / 摇号新房备案价**
- [ ] 已排除**共有产权房、保障房**
- [ ] 已排除**面积或房号无法核实、来源不明**的样本

## C. 比较基础统一（口径未统一就调整 = 把口径差当成属性差）

- [ ] 面积口径统一（建筑面积 or 套内，全样本一致）
- [ ] 价格口径统一（单价 or 总价）
- [ ] 税费口径统一（含税 / 不含税）
- [ ] 装修口径统一（含装修的已拆分或统一扣减）
- [ ] 权利口径统一（完整产权 / 受限产权）

## D. 四项调整

- [ ] **交易情况修正**：已判定非市场因素；修正幅度 > ±15% 的案例已**直接剔除**而非硬调
- [ ] **市场状况调整（期日）**：已用**有来源的指数**（本包 price-index / 官方 70 城 / hedonic 时间虚拟），未使用"市场普遍涨了 X%"这类无来源判断
- [ ] **区位调整**：距地铁/商圈/学区/朝向采光/噪音，逐项列示
- [ ] **实物调整**：面积/房型/楼层/房龄/装修/结构，逐项列示
- [ ] **权益调整**：产权完整性/限售状态/抵押情况

## E. 调整率锚点（本包核心要求）

- [ ] 调整率**优先取自 hedonic 属性隐含价格**，而非估价师经验数字
- [ ] 若无法取得 hedonic 系数 → 已在报告中**显式说明"调整率无量化锚点"**
- [ ] 已遵守"**只调差异、不调水平**"：案例与估价对象同类别的属性 → 调整为 0

## F. 幅度与离散度纪律

- [ ] 单项调整幅度 **≤ ±20%**（超出已重选案例或已披露超限理由）
- [ ] 累计调整幅度 **≤ ±30%**
- [ ] 调整后案例单价**变异系数 CV ≤ 10%**（超出须回到 B 步重选案例）
- [ ] 加权中位数与加权均值差异 **≤ 3%**（超出须说明影响点）

## G. 结果与披露

- [ ] 结果以**区间**给出（四分位区间 + 全距），**未做单点断言**
- [ ] 已列出每个案例的**权重与理由**
- [ ] 已标注口径（成交/挂牌）与**标注级**（测算/估算/研判推断）
- [ ] 挂牌口径已做→成交折算，且**折算区间已进入区间合成**（未只给一个折扣点值）
- [ ] 已列示**被排除的案例及理由**（可审计性要求）
- [ ] 已写明比较法的固有局限（依赖案例可得性、无法外推、调整主观性）

---

## 红线（出现任一项即判不合格）

1. 把挂牌价当作成交价使用而不折算、不标注；
2. 案例不足 3 个仍给出结论；
3. 调整率无依据（未提供每条调整项的依据）；
4. 只给点估计、无区间；
5. 引用无来源的市场涨跌幅作为期日修正依据；
6. 把法拍 / 限价 / 亲属交易案例混入普通案例池。
