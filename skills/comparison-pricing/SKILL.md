# 比较法（市场比较法）

## 0. 这个 Skill 解决什么问题

本包此前的结构性悖论（见评审）：**最精密的方法（SAR / GWR / Case-Shiller）从未在真实执行中被调用，而实际被调用的路径（比较法）恰恰没有方法论**。Trial Run 走的就是"比较法 + 多源中位"，却是裸奔的。

本 Skill 把比较法从"估价师的经验手艺"变成**可复现、可审计、调整率有锚点**的工艺。

**核心设计决策（本 Skill 最有价值的一点）**：

> 调整率**不取估价师经验数字**，而是优先锚定 `hedonic-pricing` 输出的**属性隐含价格**。
> 例：hedonic 给出"南向 +6.80%、高楼层 +9.20%"，则朝向与楼层差异**直接取该系数**。
> 这是特征价格模型在中国实务中最被忽视、却最实用的用途——它让比较法的调整从"拍"变成"算"。

---

## 1. 适用与不适用

| | 判据 |
|---|---|
| **适用** | 同一供需圈内有 ≥3 个可比成交案例；房地产市场活跃、案例可获取 |
| **不适用** | 案例不足 3 个；市场处于冻结期（无成交）；标的为特殊用途物业（应转成本法/收益法） |
| **必须降级的情形** | **仅有挂牌价、无成交价** → 可以走比较法，但必须做挂牌→成交折算并标注「研判推断」，且结论只能到「筛选级」 |

---

## 2. 五步作业流程

### 第 1 步：选取可比案例

**必须满足**（硬条件，不满足即排除）：
1. 与估价对象**同区域、同用途、同类型**（住宅 / 公寓 / 商住不得混）；
2. 成交时间距估价基准日一般 **≤ 12 个月**（市场波动期收紧至 6 个月）；
3. 单价量级在同供需圈合理区间内（本包 `WangqianAdapter` 内置 1e3–1e6 元/㎡ 体检）。

**必须排除**（`comparison_model.py --exclude-flagged` 自动执行）：
- 法拍房、抵债房、亲属间/关联方转让、急售（低于市场价 5% 以上且无法解释）；
- 限价 / 摇号新房的备案价（行政定价，非市场价）；
- 共有产权房、保障房（产权受限）；
- 面积/房号无法核实、来源不明的样本。

**案例数量**：≥3 个；5–8 个更稳健。**只有 1–2 个时必须声明"不具备比较法条件"**，不得硬凑。

### 第 2 步：建立比较基础（口径统一）

这是最容易被跳过、也最容易出错的一步。必须逐一统一：

| 维度 | 需统一到 |
|---|---|
| 面积口径 | 建筑面积（含公摊）或套内面积，**全样本统一** |
| 价格口径 | 单价（元/㎡）或总价（元），**全样本统一** |
| 税费口径 | 含税 / 不含税 |
| 装修口径 | 含装修 / 毛坯（含装修的须拆分或统一扣减） |
| 权利口径 | 完整产权 / 受限产权 |

> ⚠️ 本包 `pack.json` 的 `caliberDeclarations` 与本步对应。**口径未统一就做调整，等于把口径差当成属性差**。

### 第 3 步：交易情况修正

剔除非常规交易的价格偏离。修正系数 = 正常价格 / 实际成交价。

判定依据：交易双方关系、付款方式、交易动机、交易税费承担方。
**幅度纪律**：修正幅度 > ±15% 的案例应**直接剔除**，而非强行修正。

### 第 4 步：市场状况调整（期日修正）

把各案例价格调整到**同一时点（估价基准日）**：

```
调整系数 = 基准日指数 / 案例成交日指数
```

指数来源优先级：
1. 本包 `price-index` 输出的小区/片区指数（最贴合）；
2. 官方 70 城指数（独立第三方校验，见 `adapters/index70.py`）；
3. 本包 `hedonic-pricing` 的时间虚拟系数。

> ⚠️ **不得使用"市场普遍认为涨了 X%"这类无来源判断**（违反本包禁例 token）。

### 第 5 步：房地产状况调整

分三方面逐项列示，**每项必须写依据**：

| 方面 | 典型调整项 | 调整率来源（优先级从高到低） |
|---|---|---|
| **区位** | 距地铁、商圈、学区、朝向采光、噪音 | ① hedonic 属性隐含价格 ② 同小区配对样本实测差 ③ 分级打分 |
| **实物** | 面积、房型、楼层、房龄、装修、结构 | 同上 |
| **权益** | 产权完整性、限售状态、抵押情况 | 同第 3 步 |

---

## 3. 铁律（必须执行，违反即不合格）

1. **调整项逐项可见**：不得只给最终调整率。必须输出每项的名称/方向/幅度/依据。
2. **单项幅度 ≤ ±20%，累计 ≤ ±30%**（中国估价实务惯例）。超出应**重选案例**，不得硬调。
   > 若 hedonic 系数本身超过 20%（如优质学区溢价可达 30%+），应在报告中说明"该项为制度性溢价，超出常规调整幅度，故采用 hedonic 实测系数并单独披露"，而不是机械截断。
3. **调整后必须检验离散度**：三个案例调整后的单价变异系数（CV）**> 10%** 说明可比性差或调整过度，须回到第 1 步重选案例。
4. **结果必须区间化**：取加权中位数/加权均值，并给出区间。**禁止单点断言**（质量硬门 `interval-required`）。
5. **权重必须列示**：采用加权平均时必须列出每个案例的权重与理由。
6. **样本 <3 个时拒绝出结论**，不得降级为"凭经验给一个数"。

---

## 4. 权重方案（本包默认）

按可比性综合评分加权，而非简单算术平均：

| 可比性 | 权重 | 说明 |
|---|---|---|
| 同小区 + 同户型 + 面积差 <5% | 1.0 | 最优 |
| 同小区 + 不同户型 | 0.7 | |
| 同片区（同供需圈） | 0.4 | |
| 同城市不同片区 | 0.15 | 仅在案例严重不足时使用，且须披露 |

默认最终结果取**加权中位数**（对异常值稳健），同时输出加权均值作为对照 —— 两者差异大（>3%）说明存在影响点，须在报告中说明。

---

## 5. 输出结构

```
1. 可比案例表        案例编号 / 地址 / 成交日 / 成交价 / 单价 / 可比性评分 / 权重
2. 修正调整表        每个案例逐项：交易情况 / 期日 / 区位 / 实物 / 权益 → 修正后单价
3. 幅度合规检查      单项是否超 ±20%、累计是否超 ±30%、离散度 CV 是否超 10%
4. 结果              加权中位数 + 加权均值 + 区间 + 权重说明
5. 口径与限制        挂牌/成交口径、折算区间、案例数量、市场活跃度说明
```
