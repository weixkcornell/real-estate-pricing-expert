## mat-014　Ho, W.K.O. et al. (2021). *Predicting property prices with machine learning algorithms*. Journal of Property Research.

### 模型设定
在同一份住房数据上比较机器学习算法与传统特征价格回归。典型族：

- 单棵树 **CART**：递归二分，最小化子节点内平方误差；天然处理非线性和交互，但方差大；
- **随机森林（RF）**：Bootstrap 抽袋 + 随机特征子集，多树平均。袋外样本（OOB）给出**免额外切分的泛化误差估计**；
- **梯度提升（GBM / XGBoost 类）**：逐步拟合前一轮残差（函数空间梯度下降），偏差低但需早停与正则化防过拟合；
- 支持向量回归、神经网络等。

### 关键结论
- ML 在**预测精度**上普遍优于线性特征价格（非线性与交互被自动捕捉）；
- 但**可解释性下降**——这是 AVM 落地的主要障碍；
- **特征重要性**分析对业务理解不可或缺，且**不同重要性度量（分裂增益 / 排列重要性 / SHAP）给出的排序可能不同**，需说明所用度量。

### 估计与评测纪律
- 必须 **K 折交叉验证**或**时间切分**（房地产有时序性，随机切分会高估精度）；
- 报告 `MAE` / `MAPE` / `R²`，并**与线性基准对比**（否则无法说明 ML 带来了什么）；
- **超参数不得用测试集调**（本次实现中已暴露过同类问题：GP 超参若靠样本内似然选到边界，会得到虚假的高精度）。

### 数据要求
样本量需求显著高于线性模型（树模型每层分裂都消耗样本）。**小样本（n < 200）上 ML 通常不如线性模型** —— 本包纪律：n 不足时应**主动拒绝** ML 规格并降级到 hedonic/比较法，而非给出不稳定的预测。

### 中国适配注意点
- 中国数据里**缺失值本身带信息**（"装修未知"可能与老旧小区相关），不要无脑插补；树模型可原生处理缺失（如 XGBoost 的默认方向），但需在文档中说明。
- 训练样本的**时间跨度必须覆盖完整政策周期**，否则模型学到的是政策期片段的规律。

## mat-015　（2022）*Irish Property Price Estimation Using A Flexible Geo-spatial Smoothing Approach*. JREFE. DOI 10.1007/s11146-022-09888-y

### 模型设定（**高斯过程空间平滑 + 预测区间**——本包 GP-AVM 的依据）
爱尔兰房价估值系统面临的典型困境：**交易稀疏、标的异质** → 需要的不只是点估计，而是**带不确定性的估值**。

方法：把价格建模为"属性 + 空间坐标"上的**灵活平滑函数**（高斯过程 / 平滑样条类）：

```
f ~ GP(m(x), k(x, x′))
k(x, x′) = σ_f² · exp(−½ Σⱼ ((xⱼ − x′ⱼ)/ℓⱼ)²) + σ_n² · δ(x, x′)
```

**后验预测**：

```
μ(x*) = k*ᵀ (K + σ_n²I)⁻¹ y
σ²(x*) = k(x*, x*) − k*ᵀ (K + σ_n²I)⁻¹ k*
```

区间：`μ(x*) ± z₁₋α/₂ · σ(x*)`。

### 关键方法论要点
- **不确定性是该方法的核心产出**，不是副产物。论文的贡献正在于：在小样本/低换手市场，**点估计不足，必须量化不确定性**。
- 超参数 `(ℓ, σ_f, σ_n)` 由**对数边际似然**最大化确定：
  `log p(y|X) = −½ yᵀK⁻¹y − ½ log|K| − n/2 · log(2π)`；
  网格搜索或梯度优化均可，**但必须检查最优解是否落在搜索边界**——撞边界说明网格设窄了，结果不可信。
- **区间覆盖率（coverage）必须验证**：名义 95% 区间在留出集上的实际覆盖率应接近 95%。若覆盖率远低于名义值，说明区间被低估。

### 已修复的实现缺陷（**量纲失配**，来自本包 R4 迭代）
高斯过程要求核幅 `σ_f` 与**因变量的量纲**匹配。若只标准化自变量 `X` 而**不标准化因变量 `y`**，价格量纲（元/㎡，量级 10⁴）会让初始 `σ_f`（量级 1）严重失配 → 核矩阵退化 → `log|K|` 爆炸（实测 −3.2×10⁸）→ **区间宽度塌缩到 1 元/㎡、覆盖率 0%**。

→ 正确做法：**X 与 y 同时标准化**，得到预测后再还原量纲。`ml_valuation.py` 已修复。

**一般性教训**：任何核方法（GP、核岭、SVR）中，输入与输出都应处于可比的数值尺度，否则核幅超参的搜索会失效。

### 数据要求
坐标 + 属性 + 价格。GP 的计算复杂度为 `O(n³)`（矩阵求逆）→ **n 超过约 3000 时纯 Python 实现不实用**，需改用诱导点/稀疏近似或换 GBM+conformal 区间。

### 中国适配注意点
- 中国小城市/县域成交极稀疏，正是该方法的最佳适用场景 —— 但需以**城市内分片区**建模（每片区独立 GP），而非全市一个大 GP。
- 区间宽度本身是**有业务价值的输出**：区间过宽意味着"这个标的缺乏可比参照，无法给出可靠估值"，应作为**拒绝估值的依据**（对应本包 `interval-required` 硬门的正向使用）。

## mat-016　Kok, N., Koponen, E.-L. & Martinez-Barbosa, C.A. (2017). *Big Data in Real Estate? From Manual Appraisal to Automated Valuation*. Journal of Portfolio Management, 43(5).

### 模型设定（行业视角）
从**人工评估（manual appraisal）向自动估值（AVM）**演进的行业分析。要点：

- AVM 的价值不在"替代评估师"，而在**批量、高频、可复现**的估值监测（如抵押品价值监控、REITs 组合估值、指数构建）；
- **精度目标与用途匹配**：贷款抵押场景对高估（over-valuation）容忍度极低（须偏保守），组合监测场景更看稳定性与一致性；
- **AVM 的失效模式**：非常规物业（独特建筑、特殊用途）、缺乏可比交易的市场、结构突变期（政策或市场转折）——恰是人工评估价值最高的场景。

### 对方法的约束（关键）
该文隐含一条重要纪律：**AVM 必须输出误差分布，不能只给点估计**，因为下游用途（授信额度、拨备）需要的是**保守分位**（如 5% 分位）而非均值。

→ 这直接支撑本包 P1-2 的改动：为 RF/GBM 等无原生区间的模型补 **conformal 预测区间**，使全方法族都能输出分位数。

### 数据要求
讨论性文献，无特定数据要求。实务上 AVM 标定需覆盖目标市场的**全样本期**，且必须做**回溯测试（backtesting）**。

### 中国适配注意点
- 中国 AVM 的主要用途是**银行抵押物价值监测与贷后管理**，受《商业银行押品管理指引》类规则约束 → 估值应默认输出**保守区间下界**并披露方法限制。
- 中国大量存量房缺少完整属性（尤其装修、结构），AVM 须内置**置信度分层**（属性完整度 → 输出精度等级），本包 `data_rules` 的"四级标注"即为此设计。
