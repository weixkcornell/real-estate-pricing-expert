## 一、比较法（市场比较法）—— 最高频路径的完整工艺

### 1.1 基本式

```
估价对象价值 = 可比案例成交价 × Π(各项修正系数) / Π(各项调整系数)
```

或采用**百分率调整**的线性形式：

```
V = P_c × (1 + Σ aᵢ)        aᵢ 为各项差异的调整率
```

实务中两种形式并存：**连乘（系数修正）**用于交易情况、市场状况等整体性因素；**连加（百分率）**用于区位、实物状况等分项差异。**同一报告内不应混用两种形式而不说明。**

### 1.2 五步作业流程

| 步 | 动作 | 关键纪律 |
|---|---|---|
| 1 | **选取可比案例** | 至少 3 个；优先同小区同楼栋同户型；成交价优于挂牌价 |
| 2 | **建立比较基础** | 统一口径：面积（建筑面积/套内）、单价或总价、含税/不含税、含装修/毛坯 |
| 3 | **交易情况修正** | 剔除非常规交易：法拍、亲属间转让、抵债、限价房、急售 |
| 4 | **市场状况调整（期日修正）** | 把各案例价格调整到**同一时点**（估价基准日）；用官方指数或本包指数 |
| 5 | **房地产状况调整** | 区位、实物、权益三方面逐项列示 |

### 1.3 可比案例选取标准（可操作版）

**必须**：
- 与估价对象**同区域、同用途、同类型**（住宅 vs 公寓 vs 商住不得混）；
- 成交时间距估价基准日一般不超过 1 年（市场波动大时收紧至 6 个月）；
- **成交价**优先；仅能取得挂牌价时必须做**挂牌→成交折算**并标注。

**禁止**（应剔除）：
- 法拍房、抵债房、亲属间转让、含家具家电打包价未拆分；
- 限价/摇号新房备案价（行政定价，见知识块 06）；
- 共有产权、保障房等产权受限样本；
- 面积或房号存疑、无法核实来源的样本。

### 1.4 差异调整的纪律（**防幻觉的核心**）

评审指出"比较法裸奔"的风险正源于此：**调整幅度是主观的，但没有纪律就会变成拍数字**。本包要求：

1. **调整项必须逐项可见**：不得只给最终调整率，须列出每一项的名称、方向、幅度、依据；
2. **单项调整幅度上限**：实务惯例单项调整一般不超过 ±20%，多项累计不超过 ±30%（超出应重新选案例，而不是硬调）；
3. **调整依据须可追溯**：优先用本包模型输出的**属性隐含价格**作为调整率依据（如 hedonic 给出"南向 +6.80%、高楼层 +9.20%"，则朝向差异直接取该系数），而非估价师经验数字——**这是特征价格模型在中国实务中最容易被忽视、却最有价值的用途**；
4. **调整后必须检验离散度**：三个可比案例调整后的单价**变异系数（CV）过大**说明案例可比性差或调整过度；
5. **结果区间化**：取加权中位数/加权均值，并输出**区间**（本包质量硬门 `interval-required` 禁止单点断言）。

### 1.5 权重合成

| 方法 | 适用 | 本包纪律 |
|---|---|---|
| 简单算术平均 | 案例可比性相当 | 需说明为何等价看待 |
| 加权平均 | 可比性有差异 | **必须列出权重与理由** |
| 中位数 | 存在可疑样本 | **推荐默认**——对异常值稳健 |
| 众数 | 大量同质样本 | 仅适用于批量评估 |

**本包默认权重方案**：按"可比性综合评分"加权（同小区同户型 1.0、同小区异户型 0.7、同片区 0.4），并在输出中列出权重表。

### 1.6 比较法的固有局限（必须写入报告）
- 依赖**可比交易的可获得性**；市场冷清时无法使用（此时应转向收益法/成本法）；
- **无法外推**：只能解释"相对可比案例"的价值，不含前瞻信息；
- **调整的主观性**是最大风险源，故本包要求调整依据尽量锚定模型输出而非经验。

## 二、成本法

### 2.1 基本式

```
房地产价值 = 土地取得成本 + 开发成本 + 管理费用 + 销售费用 + 投资利息 + 销售税费 + 开发利润
```

或**积算**形式：

```
价值 = 土地重置成本 + 建筑物重置成本 − 建筑物折旧
```

### 2.2 关键参数与陷阱

| 项 | 要点 | 陷阱 |
|---|---|---|
| 土地取得成本 | 出让金（起始价/成交价）+ 相关税费 | 不得用**评估地价**反推后再去算房价（循环） |
| 开发成本 | 建安工程费、前期费用、基础设施、公共配套 | 建安单价应按**当期**、按结构类型分档 |
| 开发利润 | 按**社会平均利润率**或行业惯例 | 不得用项目实际利润率（那是项目业绩，不是市场成本） |
| 投资利息 | 按开发期**均匀投入**假设分段计息 | 计算基数含土地与开发成本，不含利润与税费 |
| 建筑物折旧 | 物理、功能、经济折旧三项 | 房龄法（直线法）过于粗糙；经济折旧须独立判断 |

### 2.3 适用与不适用
- **适用**：市场交易稀疏（新建区、特殊用途物业、工业厂房）、评估**重置价值**、保险与税务场景；
- **不适用**：住宅市场的**正常交易估值**——中国住宅价格中含大量区位与制度租值，成本法会系统性低估（成本与价格无稳定关系）。

### 2.4 中国适配注意点
- 土地出让金分**起始价 / 成交价 / 楼面地价**多种口径，须统一到"楼面地价"再进入测算，并注明是否含配建要求（保障房配建、自持比例会显著改变实际地价）；
- 建安成本应区分配套标准的时代差异：同一结构类型下，2000 年代与 2020 年代的交付标准（电梯、外墙、智能系统）差异巨大 → 重置成本须按**建成年份分档**，不能全市一个均价。

## 三、假设开发法（剩余法）—— 土地定价核心

### 3.1 基本式

```
土地价值 = 开发完成后的房地产价值 − 开发成本 − 管理费用 − 销售费用
           − 投资利息 − 销售税费 − 开发利润 − 取得土地税费
```

或写成静态形式：

```
V_land = V_developed / (1 + 综合折现或利润率) − 各项后续投入
```

### 3.2 关键结构

| 项 | 说明 |
|---|---|
| 开发完成后价值 | 用**比较法**或**收益法**估计（不可用成本法——否则循环） |
| 后续开发成本 | 建安 + 前期 + 基础设施 + 公共配套 |
| 销售税费 | 增值税、土地增值税、销售费用 |
| 开发利润 | 社会平均利润率 × (土地价值 + 开发成本) 或 × 开发完成后价值（两种口径须择一并说明） |
| 动态法 | 引入**开发期现金流**与折现率，替代静态利息与利润 |

### 3.3 最易出错处（**利润计算基数的循环**）
静态法中若把利润基数设为"土地价值 + 开发成本"，而土地价值正是待求量，会形成**代数循环**：

```
V = V_dev − C − p·(V + C)      ⇒      V = [V_dev − C(1 + p)] / (1 + p)
```

必须用**解方程**方式处理，不能迭代估计。本包 `cost_residual.py` 已按解析解实现。

### 3.4 中国适配注意点
- 出让条件中的**配建、自持、限价、限售**都会实质改变剩余价值，必须在测算中显式建模，否则高估地价；
- 土地增值税采用**超率累进**，对开发利润影响显著 → 不可用简单比例税费率替代；
- 开发期假设（工期、预售条件）在中国受**预售资金监管与施工许可**约束，须按当地规则设定，不能套用一般工期。

## 四、三法并用与中国实务的"权重裁决"

| 方法 | 最适合回答 | 中国住宅实务位次 |
|---|---|---|
| 比较法 | 市场愿意出多少 | **首选** |
| 收益法 | 现金流值多少 | 次选（租金市场活跃时权重提高） |
| 成本法 | 重置要花多少 | 住宅交易估值的**下限校验**，不作主结论 |
| 假设开发法 | 土地值多少 | 土地与在建工程**首选** |

**多法并用时的纪律**（与本包场景 DAG 的"双视角交叉验证"一致）：
1. 各法结果**并列呈现**，不做静默择优；
2. 若各法差异超过**容差阈值**（本包场景设定 |A−B|/A > 15%），触发**差异归因**，逐项排查口径与假设；
3. 最终结论须标明**主要依据的方法**与**权重理由**，并给出综合区间。
