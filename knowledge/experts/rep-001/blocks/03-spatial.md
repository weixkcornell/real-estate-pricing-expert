## 空间依赖 vs 空间异质：两个必须分开处理的问题

这是本族全部文献的共同起点，也是中国实务中最常被混淆的一点：

| 问题 | 含义 | 处理工具 | 若忽略的后果 |
|---|---|---|---|
| **空间依赖**（spatial dependence） | 邻近物业价格同向联动（可比性、外部性、共同冲击） | 空间权重矩阵 + SAR / SEM / SDM | 系数标准误被低估 → 显著性虚高、区间过窄 |
| **空间异质**（spatial heterogeneity） | 同一属性的隐含价格**随区位变化**（如学区在城中心溢价高、在郊区溢价低） | GWR / 空间扩展 / 变系数模型 | 只得到"全市平均"系数，掩盖结构性差异 |

**判断路径**：先做 Moran's I 检验依赖；再用 GWR 的局部系数或其变异检验异质。**两者都不显著才可用全局 OLS。**

## mat-010　Brunsdon, C., Fotheringham, A.S. & Charlton, M. (1996). *Geographically Weighted Regression: A Method for Exploring Spatial Nonstationarity*. Geographical Analysis, 28(4), 281-298.

### 模型设定
对**每一个位置 i** 单独做一次加权最小二乘：

```
β̂(i) = (Xᵀ W(i) X)⁻¹ Xᵀ W(i) y
```

`W(i) = diag(w_i1, …, w_in)`，权重由核函数给出。常用核：

```
高斯核：   w_ij = exp(−½ · (d_ij / b)²)
双平方核： w_ij = (1 − (d_ij/b)²)²  当 d_ij < b，否则 0
```

其中 `b` 为**带宽**。带宽越大 → 趋近全局 OLS；越小 → 系数越"局部"但方差越大。

### 关键方法与易错点
- **带宽选择是 GWR 的核心决策**，标准做法：
  - 交叉验证 CV：最小化 `Σ (y_i − ŷ_{−i}(b))²`（`ŷ_{−i}` 为**剔除 i 点**的预测，避免自影响）；
  - AICc：小样本（n 较小时）更稳健，同时惩罚有效参数个数。
- **有效参数个数（effective df）**不等于 `n×k`，需由 `tr(S)`（帽子矩阵迹）计算；GWR 的 AICc 依赖此值，算错会导致带宽被系统性选小。
- **CV 与 AICc 给不同带宽时**：AICc 偏向解释与稳健，CV 偏向预测。本包纪律：**报告两者，并说明选定依据**；若差异显著（如 `b` 相差 > 30%），必须报告两套结果而非择一。
- n 太小时 GWR 不可用（每个局部回归自由度过低）。**经验下限 n ≥ 100 且在带宽内至少 ≥ 30 个点**；n = 60 的样本上做带宽选择没有统计意义（评审已指出演示数据规模问题，见知识块 07）。

### 数据要求
每个样本需坐标（投影坐标优于经纬度，避免高纬度的距离畸变）+ 属性矩阵。坐标精度必须与被估价值的空间尺度匹配（小区级估值用经纬度即可，单栋估值需要更高精度）。

### 中国适配注意点
- 学区边界、轨道交通站点、行政区界都是**非连续的属性价格断点**，高斯核会把这些断点"抹平"。→ 中国场景应优先考虑**双平方核 + 较小带宽**，或改用"按学区/街道分层"的局部模型。
- 城市间坐标系与投影不统一，跨城市 GWR 无意义（局部性假设被距离口径破坏）。

## mat-011　Bitter, C., Mulligan, G.F. & Dall'erba, S. (2007). *Incorporating Spatial Variation in Housing Attribute Prices: GWR vs Spatial Expansion*. Journal of Geographical Systems, 9(1), 7-27. DOI 10.1007/s10109-006-0028-7

### 模型设定（**GWR vs 空间扩展法**）
比较两种处理空间异质的手段：

- **空间扩展法（spatial expansion / trend surface）**：把坐标（或其多项式）与属性做**交互**，参数全局估计：
  `y = β₀ + Σⱼ βⱼxⱼ + Σⱼ γⱼ(xⱼ·s) + Σⱼ δⱼ(xⱼ·t) + ε`（`s, t` 为坐标）
  属性价格随空间**呈参数化的平滑趋势**（如线性梯度）。
- **GWR**：不预设趋势形式，系数随位置自由变化。

### 结论与选用判据
- **GWR 更灵活但参数爆炸**（每个位置一套系数），易过拟合、解释性下降；
- **空间扩展法**在"属性价格随区位呈系统性梯度"（如市中心 vs 郊区）时更简洁、更可解释，且参数可做常规显著性检验；
- 该文支持：当异质结构**近似平滑且可参数化**时，空间扩展法以更少参数达到相近拟合。

**实务判据**：先试空间扩展法（若系数显著则已足够），再考虑 GWR。**本包 `hedonic_model.py` 的 `spatial-expansion` 规格即对应此法。**

### 数据要求
同 GWR（坐标 + 属性），但参数少，对样本量要求低于 GWR。

### 中国适配注意点
中国城市的价格梯度常呈**"中心—次中心"双峰**而非单调衰减（源于多中心规划与新区建设），线性趋势项不足 → 需纳入坐标二次项或改用按行政/商圈分层的扩展法。

## mat-012　Pace, R.K. & LeSage, J.P. (2004). *Spatial Statistics and Real Estate*. JREFE, 29(2), 147-166.

### 模型设定（**空间计量的方法地图**——本族的总纲）
系统梳理房地产空间计量的模型族与估计方法：

**空间滞后模型（SAR / spatial lag）**——价格被邻近价格影响：
```
y = ρWy + Xβ + ε
```
`W` 为空间权重矩阵（常行标准化），`ρ` 为空间自回归系数。经济含义：**可比性传导 / 价格发现**（邻区成交影响本区定价）。

**空间误差模型（SEM / spatial error）**——遗漏的区位因素在空间上相关：
```
y = Xβ + u,   u = λWu + ε
```
含义：存在**未观测区位变量**（景观、噪音、社区品质）在空间上聚集。

**空间杜宾（SDM）**：`y = ρWy + Xβ + WXθ + ε`，同时含邻居的解释变量。

### 关键方法与易错点
- **权重矩阵构建**：距离型（反距离 / 距离衰减）、K 近邻（KNN）、邻接型（queen / rook）。不同 W 给出不同 `ρ`，**必须报告 W 的构造并把结果对 W 做敏感性检验**。本包目前实现了距离型与 KNN；**邻接型（queen / rook）尚未实现，列为路线图**（评审 P3-2 已指出）。
- **估计**：MLE 需处理 `ln|I − ρW|` 的雅可比项（集中似然）；或贝叶斯 MCMC。`ρ` 的取值域受 W 特征值制约。
- **OLS 直接估计 SAR 会产生联立偏误**（`Wy` 与 `ε` 相关），不可用。

### 已修复的实现缺陷（**SEM 的维度陷阱**，来自本包 R3 迭代）
SEM 的集中似然需要用 `(I − λW)` 对**数据做变换**，其中对 `X` 的变换**必须逐列施加**：

```
AX[:, j] = (I − λW) · X[:, j]        ✅ 对每一列做矩阵-向量乘
```

若误写成"对 X 的每一行做矩阵-向量乘"（`A·X[i, :]`），维度错配 → 设计矩阵退化 → 求逆奇异并在 OLS 处直接报错。**此错误语法正确、静态检查无法发现**，必须靠"已知真值的合成数据 + 数值稳定性检查"才暴露。`spatial_model.py` 已修复。

### 数据要求
坐标 + 属性 + 足够的样本密度（W 的构建要求每个点有邻居；稀疏点会让 W 退化为单位矩阵，`ρ` 不可识别）。

### 中国适配注意点
- 中国城市存在**行政边界造成的空间断裂**（跨区学区/落户资格突变），统一距离型 W 会跨边界"泄漏"效应 → 建议构造**边界阻断型权重**（跨行政区权重置零或衰减）。
- 新区与老城的空间依赖强度差异大，应在报告中对分区域估计 `ρ`。

## mat-013　（2019）*Modelling Housing Rents Using Spatial Autoregressive Geographically Weighted Regression: Cracow, Poland*. ISPRS IJGI, 8(6), 346. DOI 10.3390/ijgi9060346

### 模型设定（**SARGWR**——依赖与异质同时处理）
把 SAR 与 GWR 合成：局部回归中同时纳入**空间滞后的租金**：

```
y_i = ρ_i · (Wy)_i + X_i β(i) + ε_i
```

即**空间自回归系数本身也是局部的**（`ρ_i` 随位置变化）。适用于租金市场——租赁的"可比性"传导比买卖更强（租客决策半径小）。

### 结论
在租金数据上，SARGWR 相对全局 SAR 与纯 GWR 均有改善，说明**依赖与异质在城市租金市场同时显著**，不能只处理其一。

### 数据要求
租金面板 + 坐标 + 属性。租赁样本量大但属性披露质量通常低于买卖（装修、朝向常缺失）→ 需做属性缺失的显式处理。

### 中国适配注意点
- 中国租赁市场**机构化程度低**（个人房东占多数），租金报价与成交差异大，"押一付三/年付折扣"等支付条款会扭曲名义租金 → 建模前须统一为**等效月租**（见知识块 05）。
- 合租/分租普遍，样本中须剔除"单间出租"以避免把房间数当整租属性。

## mat-008　Oust, A., Hansen, S.N. & Pettrem, T.R. (2019). *Combining Property Price Predictions from Repeat Sales and Spatially Enhanced Hedonic Regressions*. JREFE. DOI 10.1007/s11146-019-09723-x

### 模型设定（**预测合成 + 回归克里金**）
两条线：
1. **预测合成**：分别用重复销售模型与空间增强特征价格模型预测价格，再**合成**两个预测（加权平均 / 回归合成），降低单一模型的偏误；
2. **空间增强**：在特征价格中引入空间结构（空间固定效应、空间滞后、或**回归克里金**：先回归取趋势，再对残差做空间插值）。

**回归克里金（regression kriging）**的形式：

```
步骤 1：y = Xβ + r          （OLS 拟合趋势）
步骤 2：对残差 r 拟合变异函数 γ(h)（指数型 / 球型 / 高斯型）
步骤 3：ŷ(x*) = x*ᵀβ̂ + Σᵢ wᵢ·r̂ᵢ   （对残差做普通克里金插值，带无偏约束 Σwᵢ = 1）
```

### 已修复的实现缺陷（**克里金的"假精度"陷阱**，来自本包 R3 迭代）
普通克里金是**精确插值器**：在已知观测点上，残差插值必然精确复现该点观测值 → 样本内 `R² = 1.000`、`MAE = 0`。这不是模型优秀，是**自我实现的假象**。

→ **评测必须改用留一法（LOO）样本外指标**：逐个剔除点 `i`，用其余点预测 `i`。`spatial_model.py` 已修复。

**方法论要点**：任何插值/平滑类方法（克里金、GWR、样条、KNN）的样本内指标都不可作为精度依据，必须报告 LOO 或留出集指标。

### 数据要求
坐标 + 属性 + 成交价；变异函数拟合需要**足够多的点对**且距离分布有跨度（否则分箱为空、拟合失败）。

### 中国适配注意点
- 变异函数的 `range`（空间相关半径）在中国城市差异巨大：一线核心区常仅数百米，城郊可达数公里 → **不应跨城市复用同一个 `range`**，须逐城市标定。
- 该文"预测合成"的思路对中国特别有用：网签数据可得时用重复销售，挂牌数据可用时用空间特征价格，两者**作为两个独立证据并列**（符合本包"两源冲突显式并列，不静默择优"的纪律）。
