## mat-004　Bailey, M.J., Muth, R.F. & Nourse, H.O. (1963). *A Regression Method for Real Estate Price Index Construction*. JASA, 58(304), 933-942.

### 模型设定
**重复销售（repeat sales）**方法的开山之作。只使用**同一物业的两次成交**，把两次交易的价格比作为被解释变量：

```
ln(P_i,t₂) − ln(P_i,t₁) = Σ_t β_t · D_it + ε_i
```

其中虚拟变量 `D_it` 按"首次交易期取 −1、再次交易期取 +1、其余取 0"构造。`β_t` 即各期价格指数（相对基期）。

### 关键设计（易错点）
- **−1 / +1 的符号约定**是该方法的核心识别技巧：它使 `β_t` 恰好解释为"在 t 期买、在 t′ 期卖的纯价格变动"，而非两期各自的水平值。
- 因变量是**价差**，不是价格水平——因此所有**不随时间变化的物业属性被自动差分掉**，无需观测属性。

### 假设与局限
- 物业属性在两次交易之间**不变**（翻新、加建、改变用途会污染估计）；
- 交易价格本身含测量误差（噪声）→ 该文已指出重复销售指数可能**向上偏**（因两次价格误差的方向相反）。此偏误正是 mat-005 三阶段加权的动机。
- 只使用重复交易样本 → **样本选择偏误**：频繁换手的物业可能非随机（换手率高常与投资客、房龄或区位活跃度相关）。

### 数据要求
同一物业的**成交价**配对记录，含唯一物业标识与两个成交日期。样本量以"对数"而非"物业数"计——换手率低的城市需多年累积。

### 中国适配注意点
- 中国**缺少全国统一的物业唯一 ID**。实务上只能用"小区 + 楼栋 + 房号 + 建筑面积"做代理主键，易受门牌重编、面积口径变更影响。构建配对时必须输出**配对覆盖率**，并要求 ≥ 某阈值才可用（`data_adapter.build_repeat_sales_pairs` 已实现覆盖率计算与警示）。
- 网签数据已含成交价与时间，是中国最可行的重复销售数据源；挂牌数据不可用（同一房源多次挂牌不是"两次成交"）。

## mat-005　Case, K.E. & Shiller, R.J. (1989). *The Efficiency of the Market for Single-Family Homes*. American Economic Review, 79(1), 125-137.

### 模型设定（**三阶段加权最小二乘**——本包 `price_index.py` 的 `case-shiller` 规格）
在 BMN 基础上引入**异方差校正**。设：

```
ln(P_i,t₂) − ln(P_i,t₁) = H_it + U_it,   H_it = 物业个体增值(随机游走)，U_it = 价格观测噪声
```

则价差方差随持有间隔线性增长：

```
Var(价差) = 2σ_u² + (t′ − t)·σ_v²
```

**三阶段估计**：
1. **阶段 1**：对 `ln P_diff = Σ β_t D_t` 做 OLS，得残差 `û`；
2. **阶段 2**：把残差平方对**持有间隔**做回归，估计方差函数
   `û² = C + A·gap (+ B·gap²)`，其中 `C → 2σ_u²`、`A → σ_v²`（`B` 为可选高阶项）；
3. **阶段 3**：以拟合标准差 `ŝ = √(C + A·gap)` 的倒数为权重做 WLS，重新估计 `β_t`。

### 关键设计要点（**由本包迭代中暴露的两个真实缺陷提炼**）
- **共线性陷阱**：若样本中"持有间隔"只有 2 个取值 `{1, 2}`，则 `gap²` 是 `1` 与 `gap` 的**完全线性组合**（`g² = −2·1 + 3·g`）。此时把 `[1, g, g²]` 一起放进回归会**矩阵奇异**；朴素实现会静默退化为常数拟合，把 `σ_v` 错估为 0。→ 正确做法：**按间隔取值个数自适应决定是否纳入 `g²`**。`price_index.py` 已修复。
- **权重方向**：间隔越长方差越大 → 权重越小。效果是**削弱长持有期样本对指数的影响**——这与直觉相反，需在报告中说明理由。

### 论文的实证结论（非方法，但重要）
用该指数检验市场效率，发现单户住宅市场**非弱式有效**：过去的价格变化对后续超额收益具有预测力。这一结论被后续大量文献引用与检验。

### 数据要求
同 mat-004（重复成交配对），但**额外要求持有间隔有足够变异**——若全部样本的间隔集中在少数几个值，阶段 2 不可靠，应退回 BMN 或改混合模型。

### 中国适配注意点
- 中国二手房持有周期受**限售政策**（取得产权证满 N 年方可转让）截断，间隔分布本身被政策塑造 → 阶段 2 的方差结构会混入政策效应，报告须标注限售政策起止。
- 本包已实现的 σ_u / σ_v 输出应作为**数据质量的体检指标**：σ_u 异常大意味着成交价记录噪声高（可能混入口径不一致的样本）。

## mat-006　Case, B., Pollakowski, H.O. & Wachter, S.M. (1991). *On Choosing Among House Price Index Methodologies*. Real Estate Economics, 19(3), 286-307.

### 模型设定（**方法选择判据**——本包指数方法的选型依据）
系统性比较主流指数方法：**均值/中位数法、特征价格法、重复销售法、混合法**。核心结论：

| 方法 | 优势情形 | 失效情形 |
|---|---|---|
| 简单均值 / 中位数 | 样本同质、换手低 | **样本构成变化**时失真（composition bias）——中国新房供应结构逐年变化，此法基本不可用 |
| 特征价格法 | 属性可观测、换手低、样本可跨物业 | 属性缺失或口径变化；函数形式误设 |
| 重复销售法 | 属性不可观测、样本够重复 | 样本选择偏误；属性被翻新改变；换手率低时样本不足 |
| 混合法 | 样本中含重复与非重复两部分 | 权重设定需说明 |

**最重要的实务判断**：没有单一方法在所有情形下占优；**指数方法的选择应报告为一次显式判断，而非默认动作**。

### 数据要求
完整比较需同时具备：成交样品（含属性）+ 重复成交配对。仅有其一则无法做方法对比。

### 中国适配注意点
中国城市间数据可得性差异极大——一线城市网签数据可得、三四线仅挂牌。因此**指数方法选择必须随城市数据条件分级**（本包 `data-contracts/capability-contract.csv` 的 `fallback` 字段即为此设计）。若只有挂牌快照，按本包纪律应**拒绝出具指数**并标注「不具备指数构建条件」，而非降级出一个不可靠指数。

## mat-009　Calainho, F.D., van de Minne, A.M. & Francke, M.K. (2024). *A Machine Learning Approach to Price Indices: Applications in Commercial Real Estate*. JREFE, 68, 624-653. DOI 10.1007/s11146-022-09893-1

### 模型设定（**ML 时外误差加权指数**——本包 `price_index.py` 的 `ml-time-dummy` 规格）
商业地产换手率极低、标的极度异质 → 重复销售样本严重不足。该文思路：

1. 用机器学习模型（含属性、区位、时间）拟合价格；
2. 以**模型在时间维度上的样本外误差**（out-of-time error）作为权重；
3. 用时间虚拟变量 + 该权重构建价格指数。

关键主张：**ML 模型的时外预测误差可以作为"该笔交易信息量"的度量**——误差小（模型预测得准）的样本更可信、权重更高；这与 BMN 用残差、Case-Shiller 用间隔的加权逻辑在精神上一致，但**权重来源从"结构假设"换成了"模型表现"**。

### 估计方法
- 时间虚拟与属性非线性同时进入模型（树模型自动处理交互）→ 无需手工设定属性×时间交互项（对比 mat-007 的参数爆炸问题）。
- 需严格的时间切分（walk-forward）以避免信息泄露：预测 t 期价格时不得使用 t 期及以后数据训练。

### 数据要求
同 mat-014 的 ML 要求（大样本、属性完整），且**必须按时间排序切分**。样本量不足时该方法退化为不稳定的时间虚拟回归。

### 中国适配注意点
- 适用于**商业地产与低换手市场**（写字楼、产业园、大宗交易），是中国公募 REITs 底层资产估值的可行方向。
- 中国商业地产成交极稀疏（单城市年成交常为两位数），需以**跨城市面板 + 城市固定效应**扩样本，并把城市间口径差异作为首要风险（见知识块 05/06）。
- 时间切分在中国须避开政策密集期（如限价调整窗口），否则模型会把行政定价当作市场信号学习。
