# 知识底座（rep-001 · 置价）

本目录存放该专家的溯源材料。正式交付时放置：

- 论文 PDF 或摘要：`<标题>_<作者>.pdf`（本包方法论所依据的核心期刊论文）
- 全文合并稿：`_全文合并.txt`（供 persona 校准与观点检索）

## 要求

1. 每份材料必须在 `source/SOURCE-MANIFEST.json` 登记（出处 + 授权状态）。
2. **无授权来源不入库。**
3. persona 中的观点必须能溯源到本目录材料——编造专家观点比不回答更严重。
4. 涉密材料可只入库摘要层，溯源材料分级存放。
