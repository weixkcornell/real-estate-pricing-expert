# 合成基准数据集（benchmark）

> ⚠️⚠️⚠️ **本目录下所有 CSV 均为【合成数据 / 模拟数据】，由 `make_benchmark.py` 中写死的 DGP 人为构造，不代表任何真实市场行情。严禁当作市场数据引用、披露或对外发布。** 任何基于本数据的结论都应明确标注"合成数据"。

## 用途（对应外部评审 P2-2-a）

原方法库的演示数据仅 8 / 60 / 450 条（玩具规模），GWR 在 n=60 上做带宽选择基本不可用，用户无法在接入真实数据前系统验证实现。本基准提供 **n≈5000、已知 DGP** 的中等规模合成数据，配套真值清单，用于：

- 用 OLS / hedonic 还原已知线性系数真值；
- 用 BMN / Case-Shiller 还原已知真实价格指数序列；
- 用 `stratified_rent_index` 还原已知真实租金指数；
- 用 GWR / SAR / SEM 检验空间异质与空间自相关处理；
- 用 GP-AVM / 回归克里金检验区间与样本外精度是否真实。

## 已知真值清单（DGP）

### 1. 房价 hedonic（半对数）

`ln(单价) = β0 + Σβ·X + γ_t（期效应）+ S(经度,纬度)（空间场）+ ε`

- 截距 β0 = 10.3000
- β[面积] = +0.0060，β[房龄] = −0.0120，β[楼层] = +0.0020
- β[到市中心距离] = −0.0150，β[到最近地铁距离] = −0.0200，β[学区] = +0.0600
- 朝向效应（朝南为参照）：北 −0.050、东 +0.010、西 −0.020、东南 +0.015、西南 −0.010
- 空间自相关：`S = 0.15·sin(3·经度) + 0.12·cos(2.5·纬度) + 0.08·sin(2·经度 + 1.7·纬度)`
- **异方差**：`ε` 标准差 `sd = 0.05 + 0.0008·面积`（随面积增大）

### 2. 真实价格指数 γ_t（对数口径，基期 t=1 归 100）

`γ_t = 0.0040·(t−1) + 0.0200·sin(2π·(t−1)/12)`，t = 1…24。

### 3. 重复成交方差结构

`Var(ln(两次成交价比)) = 2σ_u² + gap·σ_v²`，其中 σ_u = 0.0500（单次成交特异噪声），σ_v = 0.0600（随机游走单步）。持有间隔 `gap` 为数值（月，1–12），可直接检验 σ_v 是否被错估为 0。

### 4. 真实租金指数 η_t（对数口径，基期 t=1 归 100）

`η_t = 0.0020·(t−1) + 0.0150·sin(2π·(t−1)/12 + 1.0)`，t = 1…24。

### 5. 租金 hedonic（半对数）

`ln(月租) = δ0 + Σδ·X + η_t + 噪声`

- 截距 δ0 = 7.5000
- δ[面积] = +0.0100，δ[到最近地铁距离] = −0.0150，δ[学区] = +0.0400

## 使用建议

- 还原属性系数：用 OLS 在 `ln(单价)` 上对 `[1, 面积, 房龄, 楼层, 到市中心距离, 到最近地铁距离, 学区]` + **期虚拟变量**（吸收 γ_t 与空间场）回归，系数应与真值在同量级（大样本下误差很小）。
- 还原价格指数：把 `benchmark_pairs.csv` 喂给 `case_shiller_index` / `bmn_index`，所得指数应与 `exp(γ_t − γ_1)·100` 一致（容差内）。
- 还原租金指数：把 `benchmark_rent.csv` 喂给 `stratified_rent_index`，所得半对数口径指数应与 `exp(η_t − η_1)·100` 一致（容差内）。
- 空间检验：用 `经度/纬度` 构造空间权重，跑 GWR / SAR / SEM，检验空间自相关是否被正确处理。
